# PLC 循环指令引擎 (Mini Kernel 扩展)

## 概述

为 Mini Kernel 添加了完整的 **PLC 循环指令引擎**，支持类梯形图编程模型，可直接在 Shell 中编写、加载、运行、调试 PLC 程序。

## 核心特性

| 特性 | 说明 |
|------|------|
| **扫描周期模型** | 输入刷新 → 指令执行 → 输出刷新，可配置周期 (默认 10ms) |
| **指令集** | 100+ 指令：位逻辑、定时器、计数器、比较、数学、移位、跳转、PID、Modbus 等 |
| **内存映射** | X/Y/M/T/C/S (位) + D/V/R (字) 标准 PLC 地址空间 |
| **程序存储** | Flash 4 个槽位 (每槽 2KB)，掉电保持 |
| **在线调试** | 单步执行、反汇编、内存监视、断点模拟 |
| **Shell 集成** | `plc` 命令组完整管理 |

## Shell 命令参考

```bash
# 基础控制
plc help                    # 显示帮助
plc status                  # 显示运行状态、扫描统计、内存映射
plc run                     # 启动 PLC 循环执行
plc stop                    # 停止 PLC 执行
plc pause                   # 暂停 (保持状态)
plc step                    # 单步执行一条指令
plc reset                   # 复位 (清零非保持区、PC=0)

# 程序管理
plc new                     # 创建新空程序
plc load <slot>             # 从 Flash 加载程序 (slot 0-3)
plc save <slot>             # 保存程序到 Flash (slot 0-3)
plc asm <line>              # 单行汇编 (调试用)

# 调试
plc disasm [pc] [count]     # 反汇编程序
plc mem <area> [start] [cnt] # 查看内存 (X/Y/M/T/C/S/D/V/R)
plc set <area> <idx> <val>  # 设置位/字变量

# 配置
plc scan <period_us>        # 设置扫描周期 (默认 10000us=10ms)
plc wdt <timeout_us>        # 设置看门狗 (默认 100000us=100ms)
plc cfg <flag> <on|off>     # 配置: run/pause/wdt/retain/halt
```

## 汇编语法

```
指令 助记符 操作数1, 操作数2, 操作数3
; 注释以分号开头
标号:
```

### 操作数格式
| 类型 | 示例 | 说明 |
|------|------|------|
| 位变量 | `X0`, `Y1`, `M100`, `T0`, `C5` | 区域字母 + 编号 |
| 字变量 | `D0`, `V1`, `R100` | 区域字母 + 编号 |
| 常数 | `K100`, `K-50`, `0xFF` | K + 十进制 / 0x + 十六进制 |
| 标号 | `LABEL 0:`, `JMP 0` | LABEL + 数字 |

### 示例程序

```assembly
; 电机启停控制 (自保持 + 延时停止)
LABEL 0:
LD  X0          ; 启动按钮
AND M0          ; 未运行时
ORI X1          ; 停止按钮未按下 (常闭)
OUT M0          ; M0 自保持

LD  M0          ; M0 导通
OUT Y0          ; 电机输出

LD  M0
TMR T0 K50      ; 100ms基准，50=5秒延时

LD  M0
PLS M100        ; 上升沿脉冲
LD  M100
CNT C0 K1000    ; 启动计数

MOV V0 D0       ; 当前扫描周期 -> D0
MOV V1 D1       # 最大扫描周期 -> D1

END
```

## 快速开始

1. **构建固件**
```powershell
cd C:\Users\master\Desktop\work\ppCD\project\rp2040demo
.\build.bat
```

2. **烧录并连接串口** (115200-8-N-1)

3. **创建并运行 PLC 程序**
```
mk> plc new
mk> plc asm LD X0
mk> plc asm AND M0
mk> plc asm ORI X1
mk> plc asm OUT M0
mk> plc asm LD M0
mk> plc asm OUT Y0
mk> plc asm END
mk> plc run
```

4. **或从 Flash 加载预置程序**
```
mk> plc load 0
mk> plc run
```

5. **监控运行状态**
```
mk> plc status
mk> plc mem X 0 16      # 查看 X0~X15
mk> plc mem D 0 10      # 查看 D0~D9
mk> plc set X 0 1       # 置位 X0 (模拟按钮按下)
```

## 技术细节

### 扫描周期流程
```
1. 输入刷新: 读取 GPIO → 更新 X 区
2. 指令执行: PC=0 顺序执行直到 END
3. 输出刷新: 更新 Y 区 → 写入 GPIO
4. 定时器更新: 推进所有使能定时器
5. 通信/后台: 处理 Modbus/IPC 等
6. 空闲等待: 补齐扫描周期 (WDT 检查)
```

### 看门狗保护
- 默认 100ms 超时
- 单次扫描超时 → 停止运行、报错、记录错误 PC
- 可通过 `plc wdt` 调整或 `plc cfg wdt off` 关闭

### 掉电保持
- 启用 `plc cfg retain on` (默认开)
- M/S/R 区、定时器/计数器当前值、D 区在复位时保持
- `plc reset` 仅清零非保持区 (X/Y/T位/C位/D/V 非保持部分)

## 移植指南

PLC 核心 (`plc_core.c/h`) 完全平台无关，仅依赖：
- `hal_systick_get_tick()` - 获取毫秒/微秒计数
- `kmalloc/kfree` - 动态内存
- `hal_flash_*` - Flash 读写 (程序存储)

移植到新 MCU 只需实现上述 HAL 接口并在 `os_config.h` 启用 `OS_CFG_PORT_RP2040=1` (或新平台等效宏)。
